Google Calendar to Notion Daily Agenda: Sync Events Automatically

Intermediate   Apps: Google Calendar, Notion  ·  Setup: 15 minutes

Checking Google Calendar and Notion separately splits your attention across tools. Manually copying calendar events to Notion is time-consuming. This workflow runs daily to fetch all events for the current day from Google Calendar and creates a formatted daily agenda page in your Notion workspace, combining calendar data with Notion's rich formatting capabilities.

Download workflow JSON (free) Setup guide

What this workflow does

  1. A Schedule Trigger runs every morning to fetch today's events.
  2. A Google Calendar node retrieves all events for the current day.
  3. A Code node formats the events into Notion blocks with proper structure.
  4. A Notion node creates a new daily agenda page with the formatted events.
  5. The resulting page shows your complete day's schedule in Notion format.

Setup guide

  1. Import the JSON into n8n (Workflows > Import from File).
  2. Connect Google Calendar and Notion in their respective nodes.
  3. Replace REPLACE_WITH_DATABASE_ID with your target Notion database ID.
  4. Customize the event formatting in the Code node to match your preferences.
  5. Test by running the workflow manually and checking the result in Notion.
  6. Activate the schedule to run automatically each morning.

FAQ

Can I format the events differently in Notion?Yes, modify the Code node to adjust how events appear. You can change headers, add properties like duration or location, or restructure the content blocks to match your Notion workflow.
What happens if the workflow runs twice in one day?It will create duplicate daily agenda pages. To prevent this, add a check in the Code node to see if a page for today already exists, or modify the Schedule Trigger to run at a specific time only.
Will this sync recurring events correctly?Yes, Google Calendar returns instances of recurring events for the requested date range. Each occurrence will appear as a separate item in your daily agenda.
